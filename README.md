# The 52 Cetasikas

An interactive React visualization of the 52 cetasikas, the mental factors described in Abhidhamma.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are emitted to `dist/`.

## GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.

To publish:

1. Push the repository to GitHub with `main` as the default branch.
2. In the repository settings, open **Pages**.
3. Set **Build and deployment** to **GitHub Actions**.
4. Push to `main` or run the workflow manually.

The Vite base path is calculated automatically for project pages like `/cetasikas/` and user/org pages like `/username.github.io/`.
